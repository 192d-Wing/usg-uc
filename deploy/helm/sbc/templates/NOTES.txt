
USG SBC site {{ .Values.site.name | quote }} installed on node {{ .Values.site.node | quote }}.

L3 single-IP model:
  - SBC pod gets one Cilium-assigned IP from the cluster pod CIDR
  - BGP advertises the cluster's PodCIDR upstream — pod is reachable at its IP
  - Kea pod gets a separate Cilium IP, used as DHCP relay target

UPSTREAM ROUTER ({{ .Values.bgp.upstream.ip }}, AS {{ .Values.bgp.upstream.asn }}) MUST BE CONFIGURED WITH:

  router bgp {{ .Values.bgp.upstream.asn }}
    bgp router-id <upstream-router-id>
    no bgp ebgp-requires-policy
    neighbor kube-nodes peer-group
    neighbor kube-nodes remote-as {{ .Values.bgp.cluster_asn }}
    neighbor kube-nodes soft-reconfiguration inbound
    neighbor <node-ip> peer-group kube-nodes
  address-family ipv4 unicast
    neighbor kube-nodes activate
    neighbor kube-nodes default-originate
  exit-address-family

PER PHONE VLAN (DHCP relay to Kea pod):
{{- range .Values.kea.phone_subnets }}
  interface Vlan<id-for-{{ .subnet }}>
    ip helper-address <kea-pod-ip>      # discover via: kubectl -n {{ $.Release.Namespace }} get pod -l app.kubernetes.io/component=kea-dhcp4 -o jsonpath='{.items[0].status.podIP}'
{{- end }}

Verify on this cluster:
  microk8s kubectl -n {{ .Release.Namespace }} get pods -l app.kubernetes.io/instance={{ .Release.Name }} -o wide

Verify on upstream router:
  show ip bgp summary
  show ip bgp <pod-cidr>
  ping <sbc-pod-ip>
