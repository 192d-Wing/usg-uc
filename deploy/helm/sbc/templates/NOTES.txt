
USG SBC site {{ .Values.site.name | quote }} installed on node {{ .Values.site.node | quote }}.

FQDN-first L3 model:
  - SBC pod has one Cilium-assigned IP; FQDN published via ExternalDNS:
      sbc.{{ .Values.site.fqdn_base }}  →  current pod IP
  - Kea has a fixed LoadBalancer IP for DHCP relay (the one stable IP needed):
      Kea LB IP:  {{ .Values.site.kea_lb_ip }}
  - All other clients (trunks/phones/operators) reach the SBC by FQDN.

UPSTREAM ROUTER ({{ .Values.bgp.upstream.ip }}, AS {{ .Values.bgp.upstream.asn }}) BGP CONFIG:

  router bgp {{ .Values.bgp.upstream.asn }}
    bgp router-id <upstream-router-id>
    no bgp ebgp-requires-policy
    neighbor kube-nodes peer-group
    neighbor kube-nodes remote-as {{ .Values.bgp.cluster_asn }}
    neighbor kube-nodes soft-reconfiguration inbound
    neighbor <node-ip> peer-group kube-nodes
  address-family ipv4 unicast
    neighbor kube-nodes activate
    neighbor kube-nodes default-originate
  exit-address-family

PER PHONE VLAN (DHCP relay to Kea's stable LB IP):
{{- range .Values.kea.phone_subnets }}
  interface Vlan<id-for-{{ .subnet }}>
    ip helper-address {{ $.Values.site.kea_lb_ip }}
{{- end }}
